# 官方生成能力与配置

[English](generation.en.md) | [返回首页](../README.md)

Qwen Studio 2.2.4 使用 Qwen-Image-2.1 的 Diffusers 路径，按官方公开的接口、推荐配置和 Prompt Enhancer 参数接入本地生成。下表区分模型能力、应用控制和设备限制。它不是所有推理框架的合集，也不把参数接通等同于每台电脑都已实测。

## 已接入的能力

| 能力 | 应用中的入口与行为 |
| --- | --- |
| 文生图 | 图像模式；默认 2048 × 2048、40 步 |
| 单图及多图编辑 | 添加或继续修改图片；最多 10 张参考图，顺序标记为 `<image1>`、`<image2>` 等 |
| 圈选、涂抹与独立蒙版 | 点开图片 → 标注修改区域。可添加带标记的参考图，或添加原图和黑白蒙版；白色区域表示希望修改的位置 |
| 透明图生成与编辑 | 透明背景开关使用官方 RGBA 提示格式；上传、推理和 PNG 保存保留 Alpha 通道 |
| 官方生图增强 PE-T2I | 可选下载；已启用且权重就绪时，无参考图任务使用生图增强器 |
| 官方改图增强 PE-I2I | 可选下载；已启用且权重就绪时，参考图按原顺序先于文本送入改图增强器 |
| 画布比例 | 自动采纳增强器的 `wh_ratio` 或 `ratio_follow`；也可固定尺寸或跟随第一张参考图 |
| 精确文案 | 在“图中文字”填写原样文案；用户提示中的引号文案也会保留原语言并追加文字约束 |
| 反向提示词与 CFG | 高级参数；默认 CFG 为 1。反向提示词须与大于 1 的 CFG 一起使用 |
| 多张结果 | 每次 1–4 张，按顺序生成以降低峰值内存；种子从所选值逐张递增 |
| 可追溯结果 | 生成详情保留原始、增强及实际提示词、尺寸和种子；PNG 也记录实际生成参数 |
| Prefix KV cache | 显式启用官方管线的条件前缀缓存 |

标注和蒙版是模型理解的参考图，应用没有硬裁切或强制像素合成，因此未标记区域也可能发生变化。蒙版计入 10 张参考图限制。界面会把参考图编号写入待发送的提示词，发送前可修改。

## 官方 2K 尺寸

| 比例 | 尺寸 |
| --- | --- |
| 1:1 | 2048 × 2048 |
| 4:3 | 2400 × 1792 |
| 3:4 | 1792 × 2400 |
| 3:2 | 2528 × 1696 |
| 2:3 | 1696 × 2528 |
| 16:9 | 2752 × 1536 |
| 9:16 | 1536 × 2752 |

自动比例以所选尺寸的像素面积作为预算。2K 档使用上述官方尺寸；较小档保留为预览和低内存选项。跟随参考图时，在 32 像素对齐和应用尺寸范围内匹配比例。应用不会因内存不足悄悄降分辨率。

## Prompt Enhancer 下载与运行

PE-T2I 和 PE-I2I 均为可选下载，各约 18.84 GB，可按需在模型设置中安装。加上图像模型约 33.1 GB，三套权重合计约 70.8 GB；下载分段、合并临时文件和 Python 环境还会占用额外空间。首次下载需要选择 ModelScope 或 Hugging Face，后续使用相同选择。每个文件固定版本并校验 SHA-256，支持断点续传及实时速度。

增强器是官方微调的 Qwen3.5-VL 9B，不使用 Ollama 聊天模型替代。应用从对应权重目录读取 `system_prompt.txt`，开启 thinking，补齐多模态 token 类型，并使用以下官方采样设置：

| 参数 | PE-T2I | PE-I2I |
| --- | --- | --- |
| temperature | 1.0 | 1.0 |
| top_p / top_k / min_p | 0.95 / 20 / 0 | 0.95 / 20 / 0 |
| presence_penalty | 1.5 | 0 |
| max_new_tokens | 16256 | 24000 |
| 每张参考图像素上限 | 无参考图 | 1024 × 1024 像素面积 |

Presence penalty 只作用于已经生成的 token，与 repetition penalty 不同。增强结果必须是完整的有效结构，画布字段须有效；增强失败或解析失败时会改用原始提示词，并在生成详情中注明。缺少增强权重时会弹窗提醒，可选择“直接生成”。也可以在图像参数中关闭增强。

增强与生图分为先后两个独立进程。增强进程退出后，图像模型才加载。Windows 支持增强器的 CUDA/CPU 自动分配；Mac 使用 MPS。首次加载时间、可用内存和长提示词的成本需要按设备评估。

## 文字乱码：已确认与未确认的部分

此前应用默认 768 × 768，且没有使用官方 Prompt Enhancer。新版默认 2K，增加文字图表预设、指定文案和官方增强。但这些改动不能保证所有汉字都正确。

固定的 Diffusers 版本已包含 Qwen3-VL 最后一层 RMSNorm 的兼容修复；该问题在 Transformers 5 的文字输出上尤其明显。环境检测现在也检查这段兼容接口。程序未对图像提示词做 tokenizer 截断；改图参考图按像素面积处理，上传阶段不再先缩短最长边。解码继续使用原始 FP32 VAE、完整画面解码，避免分块产生接缝或彩色痕迹。

对于“生成一张讲解二战历史的流程图”，建议先确定要显示的节点与短句，再填写“图中文字”。一张图里塞入大量段落，即使 2K 也容易出错。历史内容和生成文字仍需人工校对。

本次完成接口、配置、解析、队列、取消和界面检查，没有下载 PE 权重，也没有运行新的测试图片。Windows NVIDIA 推理和双平台 PE 实际生成质量尚未在此次更新中验证。
