# Qwen Studio 2.2.4

## 中文

Mac 和 Windows 现在都可以选择模型、依赖的保存位置，也可以使用已经下载好的文件。

- 模型设置中，主模型和两个可选增强模型分别提供“选择下载目录”和“使用已有模型”。支持外置硬盘、完整模型目录和 Hugging Face 缓存快照。
- 已有模型通过本地文件检查后原地使用。首次校验有进度显示，可以停止；失败时保留原模型位置。导入不会复制权重或启动下载。
- 环境检测页增加依赖下载目录选择，以及“使用已有环境目录”。新环境、pip 缓存和安装临时文件保存在所选目录，已有可用依赖继续复用。
- 保存的目录在更新后保留。硬盘断开时提示重新连接，任务和下载期间禁止切换模型位置。
- 模型下载新增“停止下载”，保留已下载分段，停止后可选择其他目录。
- 所有新增操作和说明均支持中英文。

Windows 下载并打开 `QwenStudio-2.2.4-windows-x64.exe`，无需 setup 脚本。Mac 解压 `QwenStudio-2.2.4-macos-arm64.zip` 后打开 App。更新前关闭旧版，保留数据和模型目录。

Python、GPU 驱动和模型权重仍需单独准备。下载包不包含这些文件。模型导入只接受与应用固定清单匹配的完整 Diffusers 权重，不接受 GGUF 或 LoRA。

## English

Mac and Windows now let you choose where models and dependencies are stored, or use files you have already downloaded.

- Settings provides separate download-folder and existing-model controls for the image model and both optional enhancers. External drives, complete model folders and Hugging Face snapshots are supported.
- Existing weights are used in place after local file verification. The first verification shows progress and can be stopped. Failed imports leave the previous location selected. Importing does not copy weights or start a download.
- The environment check page adds a dependency download folder and an existing-environment folder picker. New environments, pip caches and installation temporary files use the chosen folder; working dependencies are reused.
- Folder preferences survive updates. Disconnected drives produce an actionable message, and model folders cannot be changed during tasks or downloads.
- Model downloads now have a stop button that keeps downloaded parts, allowing folder changes after stopping.
- New controls and explanations are available in Chinese and English.

On Windows, open `QwenStudio-2.2.4-windows-x64.exe`; no setup script is needed. On Mac, extract `QwenStudio-2.2.4-macos-arm64.zip` and open the App. Close the previous version before updating and keep your data and model folders.

Python, GPU drivers and model weights remain separate prerequisites and are not bundled. Model import accepts complete Diffusers weights matching the pinned manifest, not GGUF or LoRA files.
