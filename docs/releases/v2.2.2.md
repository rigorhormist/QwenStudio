# Qwen Studio 2.2.2

## 中文

本次更新同时适用于 macOS 和 Windows，合并了移动硬盘版本中的环境修复，并保留发布版的 Python 自动查找能力。

- **增强模型改为可选。** 缺少 PE-T2I 或 PE-I2I 时弹窗提醒，可选择“直接生成”，无需额外下载约 37.7 GB 的权重。已有增强模型仍按任务使用；增强失败时使用原始提示词，并在生成详情中注明。指定文字和参考图会保留。
- 环境检查只检查本软件及其依赖，不再因为其他软件的包冲突阻挡启动。独立检查并行执行，可随时停止；检测结果和操作按钮保持可见。
- 修复依赖会保留当前环境，复用可用的 GPU 依赖，在单独目录中准备修复。只有检查通过后才切换；失败或取消不会清空旧环境，也不会改动模型和会话。
- 两个平台都会记住通过检查的 Python 路径。Windows 还会记住自定义模型和会话目录，后续解压新版时可继续使用。保留对 Python Launcher、安装登记、PATH 和已安装 Store Python 的查找。
- 区分 CPU 版 PyTorch 与显卡驱动问题；修复配置损坏导致 Windows 启动直接退出的情况。新增提示、弹窗和操作均支持中英文。

### 下载与更新

- Windows：下载 `QwenStudio-2.2.2-windows-x64.zip`，完整解压后打开 `start.cmd`。
- Mac：下载 `QwenStudio-2.2.2-macos-arm64.zip`，解压后打开 `Qwen Studio.app`。
- `QwenStudio-2.2.2-source.zip` 是源码包。文件校验值见 `SHA256SUMS.txt`。

更新前关闭应用。保留原数据目录；Windows 还应保留 `settings.local.json`、`.venv`、旧版 `runtime` 和 `runtime-path.json`。如果此前使用自定义目录，首次升级请覆盖原应用目录并保留这些文件，或将 `settings.local.json` 复制到新目录。新版本通过检查后会记住位置。仍被引用的 Python 环境目录请保留。

检查覆盖依赖冲突、环境复用与切换、失败后的保留行为、Python 查找、可选增强、队列和双语界面。Mac 现有环境检查通过；Windows 和 Mac 桌面均进行构建检查。本次没有下载模型权重或运行新的生图测试，Windows NVIDIA 推理仍需实际设备反馈。

## English

This update covers macOS and Windows. It merges the environment recovery work from the external-drive build while retaining Python discovery from the published release.

- **Both prompt enhancers are optional.** When PE-T2I or PE-I2I is missing, choose Generate directly in the reminder. The extra roughly 37.7 GB of weights is not required. Available enhancers still run when enabled; failures fall back to the original prompt with a notice in Generation details. Specified text and reference images are retained.
- Checks cover Qwen Studio and its dependency graph, so unrelated package conflicts no longer block startup. Independent checks run concurrently and can be stopped. Results and action buttons remain visible while scrolling.
- Dependency repairs preserve the current environment, reuse working GPU packages and stage repairs separately. The new runtime is selected only after validation. Failures and cancellation leave the old selection, model files and conversations intact.
- Both platforms remember a runtime that passes checks. Windows also remembers custom model and conversation directories for later downloads. Python Launcher, registration, PATH and installed Store Python discovery remain available.
- CPU-only PyTorch and GPU driver failures have different recovery paths. Malformed Windows storage settings appear as a check failure instead of closing the app. New prompts and controls are available in Chinese and English.

### Downloads and updates

- Windows: extract `QwenStudio-2.2.2-windows-x64.zip` and open `start.cmd`.
- Mac: extract `QwenStudio-2.2.2-macos-arm64.zip` and open `Qwen Studio.app`.
- `QwenStudio-2.2.2-source.zip` contains source code. Verify files against `SHA256SUMS.txt`.

Close the app before updating and keep the data directory. On Windows, preserve `settings.local.json`, `.venv`, legacy `runtime` and `runtime-path.json`. For the first upgrade from a custom storage configuration, update the existing application folder or copy `settings.local.json` to the new folder. This version remembers the locations after a successful check. Keep any Python environment directory still referenced by the app.

Checks cover dependency conflicts, runtime reuse and activation, preservation on failure, Python discovery, optional enhancement, queues and bilingual UI. The existing Mac runtime passed its checks; both desktop shells are built. This update does not download model weights or run new image-generation tests. Windows NVIDIA inference still needs reports from actual devices.
