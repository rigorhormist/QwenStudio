# Qwen Studio 2.2.3

## 中文

- Windows 改为单个 EXE。界面、后端、.NET 运行时和依赖安装逻辑内置，移除外部 setup/start 步骤。
- Mac 和 Windows 均可选择已安装的 Python，查看版本、路径和虚拟环境标记，也可手动定位解释器。选择后重新检测，避免误用其他环境。
- 环境页新增官方 PyPI / 清华源选择、实时安装步骤、单文件下载进度和速度。Windows 的 CUDA 13.0 / 12.8 选择也移入页面。
- 继续复用正常的依赖，修复在独立环境中完成，通过检测后才启用。模型和会话不受影响；两个提示词增强模型仍为可选。
- 新控件和状态支持中英文。CUDA 包及 Diffusers 源码使用官方站点，依赖镜像不代替模型下载源。

### 下载

Windows 直接打开 `QwenStudio-2.2.3-windows-x64.exe`；可选 ZIP 另附使用文档。Mac 解压 `QwenStudio-2.2.3-macos-arm64.zip` 后打开 App。源码包仅用于自行构建。

Python、WebView2、驱动、Ollama 和模型权重不包含在 EXE 内。软件提供相应检测与下载入口。升级时保留旧 Python 环境和数据目录；已经通过检测的环境仍可复用。

## English

- Windows now ships as one EXE containing the UI, backend, .NET runtime and dependency installer. External setup/start scripts are no longer needed.
- Both platforms list installed Python interpreters with versions, paths and virtual-environment labels. Browse for another interpreter and recheck its dependencies before use.
- Choose official PyPI or the Tsinghua mirror in the environment page. See installation stages, per-file byte progress and transfer speed when available. Windows CUDA 13.0 / 12.8 selection is now in the app too.
- Working packages are reused. Repairs are staged separately and activated only after validation. Models and sessions are retained; both Prompt Enhancer models remain optional.
- New controls and statuses support Chinese and English. CUDA wheels and Diffusers source archives still use official sites. Dependency sources are separate from model sources.

### Downloads

Open `QwenStudio-2.2.3-windows-x64.exe` directly, or use the Windows ZIP with documentation. On Mac, extract `QwenStudio-2.2.3-macos-arm64.zip` and open the App. The source archive is for building the app yourself.

Python, WebView2, GPU drivers, Ollama and model weights are not embedded. The app checks for them and provides the relevant download entry points. Preserve existing Python environments and user data when updating.

Checksums: `SHA256SUMS.txt`. Builds are not developer-signed or notarized.
